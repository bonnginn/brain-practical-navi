# 脳弓体部・端部の追加確認 — 2026-09-16

既存の登録300 µm体部Y404–421と屈曲部Y422–434の調査を再利用し、今回は体部側のnative100 µm参照を追加した。元座標[319,404,296]、[333,410,296]、[319,416,296]で原画像・現行輪郭・旧下書き内部75格子点を並べ、9図27面を確認した。

薄い上方付着部から左右の体部様組織が続くことは見える。一方、特に右側の矢状・水平断では、旧75格子点の一部が明るい裂隙を囲んでしまう。単に原300 µm下書きの内部に格子セルが包含されることは、生存組織の内部に含まれることを保証しなかった。上方の透明中隔との分離線も独立境界として定めていない。

したがって旧75点・1,228原画像点をそのまま採用せず、内部点の追加探索もここで打ち切る。次の採用単位は、明るい裂隙を避けた体部外縁と上方／脈絡部側の境界をnative画像上で区別した一続きの区間とする。左右反転や同一多角形の反復で作らず、片側ごとの画像所見を残す。既存模式表示を維持し、新しい脳弓ラベルは追加していない。
