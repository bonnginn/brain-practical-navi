# 側脳室・海馬の開放標本：右側試作

ユーザーが提供した『プラクティカル解剖実習 脳』p.71–77の剖出写真・図を参考に、側脳室標本一つを試作した。書籍の図版や形状を複製したものではなく、BigBrain原画像と現在のラベルに対して仮想切除を設計した。参考文献は日英ブラウザ表示にも追加。

## 現在の試作

- 右半球の側脳室を上側から開放し、側頭葉側にも広い観察窓を作る。尾状核・視床・海馬を周囲組織に付いたまま残す。
- 前後方向の広い斜面切除と側頭葉側の切除を組み合わせ、残る脳室屋根をID24から上向きの開放で除く。腔全周を膨張して壁を薄皮にする処理や、固体構造ラベルの全外周をくり抜く処理は行わない。
- 無着色では全組織が共通表面・材質。着色は同じ表面を分節で区画したもの。奥の核の独立した殻は表示しない。側脳室の鋳型は組織とは別の補助で、着色段階で選択解除できる。
- 元の分節は変更していない。切除によって露出・切断された構造の範囲が変わるだけである。
- 他の7標本は今回変更していない。両側一体への展開、剖出段階の切替は未実装。現在の切り方を完成形として確定せず、ユーザーが評価できる試作とする。

## 確認と限界

既存対象試験2/2（現在ラベル・資産SHA・メッシュ構造・共通表面の重複なし）成功。型検査と通常Vite build成功。ローカル実画面で無着色／着色、鋳型の解除、回転、拡大を確認。全件試験は反復していない。

広い切除面と残存脳表を持つ試作で、実際の剖出の細かい凹凸・線維感は再現していない。海馬の全表面、脈絡叢、微細な腔壁を完全に再現したとは扱わない。切り方の教材としての適否はユーザー確認待ち。
