# 左右視索の視交叉側への延長995点

同一BigBrain標本の40 µm原画像で、既収録視索から前方へ続く腹側の左右組織帯を追い、native40 Y167–265の概略輪郭を作成した。左右の隆起と周囲との裂隙、冠状断での推移、水平・矢状断の連続を照合し、0.5 mmセルの中心で収録した。ピクセル完全一致や全角点の包含は要求せず、セル縁の部分体積を許容した。中央下面の欠損を埋めたり、旧ID33を座標だけで左右分割したものではない。

左469・右526、計995点を採用（未ラベル54・旧ID33から941）。左ID37は766点の単一成分、右ID38は708点（701・5・1・1）。両側とも今回の区間は既存の主成分へ連続する。新たな孤立4点は表示上保留し、以前からの右側小成分は変更していない。旧ID33は6,906点。

視交叉中央部までの接続、LGN側・右後方の未収録区間、視放線は残る。Y265より前方では中央下面の欠けと組織の連続を分けて判断する。今回の外縁は教材用の概略であり、線維軌跡の証明・専門家確認ではない。
