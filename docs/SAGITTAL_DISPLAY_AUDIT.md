# 矢状断を前＝左へ — 2026-09-08（未公開）

## 変更

ユーザー指定により、2D矢状断の横軸を前→後へ変更。BigBrain組織、平均T1/T2、固定脳MRI、対応ラベル、クリック同定、分節レビュー画面を揃えた。共通の断面描画を使うクイズ・ブロック内断面にも適用する。

- 画面列aを元格子の `Y=dy-1-a` へ対応。Zは上→下のまま。
- Xの選択位置・左右半球・原画像・分節ボリューム・保存差分のXYZは変更しない。
- 水平断・冠状断の対応式は変更しない。
- 分節編集の冠状断・矢状断は照合専用のまま。新しい編集機能は追加しない。
- 2D画像の端にA/P/S/I（水平・冠状ではL/Rを含む）を表示する。3D方位コンパスは従来どおり回転に追随し、2Dと見かけの向きが一致するとは限らない。
- 過去の監査図は当時の表示方向を保持し、再生成・反転・証拠ハッシュ置換を行わない。
