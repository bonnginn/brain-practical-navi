# 不透明なブロック標本への変更 — 2026-09-20

## 今回の到達点

8標本を「形を観察 → 着色して確認」に変更した。目的構造を覆う支持組織を仮想的に切り開き、標本由来の組織と構造を不透明で表示する。色を消しても構造の形は残る。透過表示を使って内部を探すことを初期学習の前提にしない。

これは教材用の仮想剖出面で、実際の摘出操作、完全な分節、専門家による形態検証を示すものではない。現行の部分分節を使った教材としての実装を一区切りとする。経路の流れる表示・クイズの拡張・公開更新は今回の範囲外。

| 標本 | 初期の形態観察と変更 |
| --- | --- |
| 側脳室 | 外側を開き、腔壁と尾状核・視床・海馬を露出 |
| 間脳 | 視床周囲を開き、第三脳室の空間と視床下核を観察 |
| レンズ核・投射線維 | 右深部灰白質と内包を上方へ露出。放線類は任意の模式補助 |
| 脳梁・脳弓 | 現行ID46の脳弓・海馬采とID43の透明中隔を0.5 mmで使用。旧手置きモデルを置換 |
| 脈絡叢周囲 | 側脳室内側と海馬を露出。脈絡叢自体は未分節で、任意の模式補助のみ |
| 内側側頭葉 | 右海馬・扁桃体・海馬采の一部を上方へ露出 |
| 中脳横断 | 原画像の組織外形を使い、赤核・黒質を露出。水道は現行部分分節の鋳型 |
| 橋・延髄・小脳 | 小脳の右外側部を残して背側を開き、第四脳室と脳幹を観察 |

腔の着色は空間の鋳型であり、組織ではない。脈絡叢、放線、小脳脚・菱形窩の個別隆起等は実測境界ではないため、初期表示から外し「模式補助も表示」で追加する。未収録の海馬采前端、透明中隔付着部などは引き続き未収録。
