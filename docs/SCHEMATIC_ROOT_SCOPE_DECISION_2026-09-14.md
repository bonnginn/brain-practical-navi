# V・IX–XI模式神経根の修正範囲 — 2026-09-14

## 2026-09-15：模式モデルの採用基準を変更

ユーザーは「ほかの資料などから、おおよその場所があってればよい」と指示した。**模式モデルでは、解剖資料による概略の出現部・走行を採用できる**。以下の過去記録にある「同一標本で実神経を同定するまで置換不可」は、模式モデルの必須条件としては撤回する。標本由来分節の根拠基準は維持する。

模式表示の採用条件は、資料に対応する出現面と概略走行、周囲の表示組織への不自然な貫入がないこと、位置・走行が模式的である旨の日英表示、収載端と省略範囲の明示とする。複数方向の全体像・拡大像で確認する。細かな根糸数、感覚根／運動根の分離や全長は、根拠と教材上の必要性がある場合だけ追加する。別標本のラベルを実標本分節へ転写する許可ではなく、専門家監修済みとも扱わない。

既知の組織貫入がある現行V・IX–XI管は、この変更だけで正しい配置と認定しない。配置修正までの表示除外と名称・機能説明の保持は独立して進める。置換後の再表示・クイズ再開は表示と出題の整合を確認して判断する。原画像上の付着部についてユーザーの回答を待つことは、模式モデル修正の前提にしない。

## 結論

V・IX・X・XIは、左右一対の単一管で近位走行を示す**模式3D**である。BigBrain組織像から神経根や根糸を抽出した形状ではない。既存画像レビューで現行管がVでは側頭葉組織、IX–XIでは小脳組織へ入る配置欠陥を確認しているため、正しい経路の同定図として扱わず、4構造の名称同定4問と機能4問、計8問の出題保留を維持する。

現時点では置換経路を採用しない。Vの単純な短縮は太い短いstubだけを残し、感覚根・運動根の正しい近位表示にならない。IX–XIも、保持できる脳外近位部と実際の出現部が原画像から確定していないため、VII・VIIIと同じ切り詰めを機械的に適用しない。見た目を整えるための根糸追加、左右鏡像による推定、周囲の小脳ラベル削除は行わない。
