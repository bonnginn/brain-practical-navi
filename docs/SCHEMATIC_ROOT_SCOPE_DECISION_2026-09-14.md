# V・IX–XI模式神経根の修正範囲 — 2026-09-14

## 結論

V・IX・X・XIは、左右一対の単一管で近位走行を示す**模式3D**である。BigBrain組織像から神経根や根糸を抽出した形状ではない。既存画像レビューで現行管がVでは側頭葉組織、IX–XIでは小脳組織へ入る配置欠陥を確認しているため、正しい経路の同定図として扱わず、4構造の名称同定4問と機能4問、計8問の出題保留を維持する。

現時点では置換経路を採用しない。Vの単純な短縮は太い短いstubだけを残し、感覚根・運動根の正しい近位表示にならない。IX–XIも、保持できる脳外近位部と実際の出現部が原画像から確定していないため、VII・VIIIと同じ切り詰めを機械的に適用しない。見た目を整えるための根糸追加、左右鏡像による推定、周囲の小脳ラベル削除は行わない。

- 全III–XII起点の中央直交断は、左右各3断面の既存sheetで確認済み。ただし連続断による根の追跡ではない。
- Vはring 0・4・12の局所直交断とnative100の代表断を確認済み。現行管の早期組織進入は示すが、実神経線維や正確な出現面は同定できていない。
- IX–XIは最深部6地点の54局所断、native300の15断面、起点近傍6 sheet・54断面、広域水平断を確認済み。現行管の小脳内進入は示すが、個々の根糸や出現座標は同定できていない。

## 次に必要な証拠

形状を修正する前に、Vでは橋外側面と三叉神経根が同時に読める連続断、IX–XIではオリーブを含む延髄外側面と根の付着列が同時に読める連続断が必要である。標本内で神経が切断・欠損している場合は、出現面までを教材に収録する上限とし、その先を推定して延長しない。外部資料はgross relationshipの比較に使い、別標本の座標や根糸数を転写しない。

新しい同一標本の境界証拠が得られるまでは、現行meshを欠陥開示付きの保留表示として残し、クイズ8問を再開しない。この判断はAI支援によるプロジェクト内判断で、専門家確認ではない。ラベル、mesh、アプリ表示、公開版、mainは変更していない。
