## 現行値と古いmetadataの区別

現行の脳室系は計184,772 voxel。そのうち20,072点の表示用原画像値は背景コード255以外だった。古いmetadataの「空間だけに限定／重なり0」は現行値を表していなかったため、当時の値を `historicalGenerationClaims` に保存し、現在の実測値へ更新した。

**20,072点を誤分節と数えたものではない。** 部分容積、画像再標本化、表示用の輝度符号化を含む「背景値以外との重なり」であって、組織への侵入を自動認定する指標ではない。輝度だけで一括除去しない。

```sh
node scripts/refresh_segmentation_measurements.mjs --check
# ラベルの採用後、実測値を確認してから更新する場合だけ
node scripts/refresh_segmentation_measurements.mjs --write
```

現行asset・metadata不一致を回帰テストで検出する。寸法が一致することを解剖学的registrationの正確性とは呼ばない。
