# βから正式版1.0へ

2026-09-22ユーザー指示に基づく開発方針。現在の公開版は0.1.0-beta.1。正式版の公開は別途の管理者承認が必要。

## 1.0の到達点

主要構造を、位置・形・機能の説明とともに観察し、復習まで自力で進められる教材にする。全構造の精密分節は要件にしない。学習内容を先に示し、部分分節・模式表示の区別を必要箇所へ短く添える。

| 段階 | 作業 | 終了条件 |
| --- | --- | --- |
| 1 | 読込・更新、操作、狭い画面とキーボードの問題を修正 | 代表的な学習操作を最後まで行える。実機で未確認の範囲は別に残す |
| 2 | 位置・見分け方・主な機能・関連構造の説明と英訳を整える | 表示・説明・クイズが食い違わず、学習者が観察に使える |
| 3 | 脳表→断面→回路→復習の入口と学ぶ順序を用意 | 次に何を観察し、何を説明できればよいかが分かる |
| 4 | 少人数の試用で操作・説明の問題を集める | 学習を妨げる主な問題を修正し、再確認する |
| 5 | 正式機能・試作・制限を確定して公開準備 | 重大な既知不具合がなく、収録範囲が明確。管理者が公開を承認する |

人の協力が必要：物理タッチ端末・Safari/PWA実機の操作、学生等の試用、専門家確認の手配と最終公開判断。専門家監修はβ必須条件から除外済み。1.0の必須条件にするかは未決定であり、開発側で勝手に追加しない。専門家確認を受ける場合は主要な取り違え、回路方向、機能説明、クイズ正答を優先する。

## 試用の短い手順

名前・学籍番号・成績等を集めず、操作上の問題と教材の分かりにくさだけを記録する。説明を先回りせず、困った時点を観察する。

1. Homeから脳表へ進み、構造を選び、その説明を開く。
2. 断面と3Dを見比べ、隣接する断面へ移動し、構造の着色を切り替える。
3. Papez回路を一段ずつ進め、観察画面から回路説明へ戻る。
4. 関連クイズを解き、解説と観察で答えを確認する。
5. 読み込み直し、狭い画面、キーボードで困る点がないか確かめる。

記録は「端末/ブラウザ」「操作」「期待」「実際」「再現するか」で十分。専門家評価や学習効果を測った扱いにはしない。

## 1.0を止めない項目

微小な分節外縁・小片、視放線の実標本分節、ブロック再設計、回路動画、保留8問の復活は後続候補。ブロックは実習スケッチを得てから代表標本を一つ仕上げる。分節を細分化する作業や全件試験の反復を進捗の代わりにしない。
