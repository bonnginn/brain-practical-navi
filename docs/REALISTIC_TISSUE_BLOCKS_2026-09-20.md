# 周囲組織を残すブロック標本への修正 — 2026-09-20

ユーザー確認で、前回の標本は構造の輪郭に沿って削りすぎ、実物では作りにくいと指摘された。前回の「ブロック作成完了」は実装段階の到達点であり、ユーザーの意図した標本形態には達していなかった。

## 変更

8標本を、周囲の灰白質・白質を含む厚い平面切断ブロックに作り直した。構造ラベルを種にした掘り込み、支持組織だけの切除、個別構造の閉じた殻を組み合わせる生成をやめた。原画像からブロック全体の共通表面を一度生成し、その面を現行分節によって着色区画へ分ける。無着色時は全区画が同じ材質・法線・濃淡を共有し、構造境界に人工的な溝を作らない。

- 側脳室：右半球の水平厚切り。全角を一度に露出しない。
- 間脳：周囲組織と第三脳室を含む冠状ブロック。
- レンズ核・内包：白質を残す水平ブロック。放線を剖出したとの表示はやめた。
- 脳梁・脳弓：右傍正中ブロック。脳梁・脳弓を宙に浮いた形として取り出さない。
- 脳室周囲：右矢状ブロック。脈絡叢の実測形態は含まない。
- 内側側頭葉：冠状ブロック。前後の切断面に現れる範囲を観察。
- 中脳：周囲組織と核が同じ横断面を共有。
- 脳幹・小脳：一体の傍正中ブロック。非現実的な構造単位の脱着操作を除いた。

奥の構造は組織に隠れたままにする。着色は露出面だけ。脳室の補助鋳型と任意の模式補助は引き続き実組織と区別する。単純な厚切りを基準にした改訂で、特定の実習標本の完全再現や現実の剖出手技の妥当性確認ではない。
