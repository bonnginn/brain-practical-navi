# 視交叉・近位視索：native40で境界目印を位置合わせ

9月19日の時間枠内に実施した、AIによる原画像レビュー。**分節追加・専門家確認・公開更新ではない。** [9月16日の境界決定手順](FIBER_BOUNDARY_METHODS_2026-09-16.md)のうち、CMAの目印を同一標本の40 µm画像へ位置付ける工程を進めた。

## 結果と判断

- 第三脳室の現行ラベル前端は保存済みnative40 ROI内にあった。app XYZ `[198,274,114]` はnative mm `[2.370803,18.387646,-14.938384]`、native40 index `[635.935,300.441,360.983]`。**既存ラベルの端を真の第三脳室前端と同一視しない。** 数値変換の往復誤差は解剖学的な登録精度の保証でもない。
- 前方Y290–310（17.97–18.77 mm）では、中央の腔様空間と腹側の横走組織、その左右の付着・離開が変化する。Y310以降で現行ID25がなくなることだけでは、CMAの「第三脳室が現れる最初の冠状断」を決められない。外部へ開く空間を第三脳室で埋める根拠にもならない。
- 後方の名称移行面を比較する対象は **native40 Y220–245（15.17–16.17 mm、1 mm幅）**。Y220/225/230で中央の欠けと細い組織、Y235/240/245で横方向の連続が見える。これは目視による検討範囲であり、確定した切断面ではない。欠けが標本損傷・処理・解剖学的な離開のどれかは、この確認だけでは確定しない。
- 水平Z300/340、矢状X500/575/636/700でも中央部と外側付着部の関係を確認した。後方の「二本へ分かれる位置」を連結成分の数だけで機械的に決める方法は採用しない。

**今回の採否：新しいvoxel候補、名称移行面、ID36–38は未採用。** 旧ID33を左右・座標で分割していない。外縁の観察と名称上の区切りを分け、次のトレース対象を具体化した段階である。視索遠位、視放線、脳弓柱・脚が確認済みになったわけではない。
