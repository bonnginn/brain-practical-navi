# 視覚路の短い教材動画

ユーザーの追加作業枠で制作。`work/visual-pathway-video/visual-pathway-ja.mp4`、1分58秒、1280×720・20fps、H.264/yuv420p、日本語字幕・音声なし。1,309,058 bytes。再生成は `scripts/render_visual_pathway_video.py`（先に `--proof-only` で場面確認）。既存Papez生成器のフォント・画像・符号化補助を再利用。

左視野と左眼を区別し、左眼鼻側網膜の交叉、右眼耳側網膜の非交叉、右視索での合流、右視野側の対称な対応、外側膝状体→視放線→V1を順に説明。全ノードと接続線を保持し、赤い点だけを移動する。光学図、個別の線維追跡、実測活動や伝導速度ではない。主要経路を扱い、他の投射・層や視野の単眼部は詳細化しない。

原資料は図を転載せず、Purves et al., Neuroscience 2nd ed. の [網膜対応](https://www.ncbi.nlm.nih.gov/books/NBK10944/) と [網膜神経節細胞の中枢投射](https://www.ncbi.nlm.nih.gov/books/NBK11145/) の検索可能な解説を照合。直接ページ取得はブラウザ確認ページになったため、全文読了とはしない。アプリ既存の `src/circuitTeaching.mjs` の4経路と対応を照合した。

BigBrainの既存0.5 mm画像と視交叉部分ID36・LGN ID44/45を水平断で抽出。断面全体の位置図・拡大範囲の赤枠・拡大画像を併記。断面は既存ラベルが明瞭な例示位置として選び、分節の採用根拠にはしない。LGNのSchifferほかの原データ、BigBrain、加工と原noticeを再生ページ・ZIPへ保持。各入力SHAは `inputs.json`。公開資産・分節・メッシュ変更なし。

全場面のproofを生成、左右対応・主要な本文と画像配置を目視確認。全編デコード成功、実ブラウザで118秒・1280×720を確認し、20秒・100秒への章移動、再生・一時停止を確認。専門家監修・学習効果の検証は未実施。
