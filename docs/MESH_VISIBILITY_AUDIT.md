# 小脳メッシュ・全脳視認性監査

更新日: 2026-08-15

## 変更方針

小脳葉・裂に関わるCerebrA由来の頂点と面は変更しません。隣接頂点の表示法線だけを4回平均し、法線の内積が0.18未満となる深い折れ目は平均対象から除外しました。したがって最大頂点変位は0 mmです。これは表示上のファセット感を抑える処理であり、解剖学的な形状修正や監修を意味しません。

大脳は明るい中性色、小脳は低彩度の黄褐色へ分けました。どちらも同じ2灯陰影を使い、脳溝・小脳葉の凹凸を色の塗り分けだけで消さないようにしています。分節表示でも小脳を同系統の黄褐色に統一しました。

## 数値確認

隣接面に共有される頂点法線の内積を表示の連続性指標として比較しました。1に近いほど隣接部の照明変化が連続します。

| メッシュ | 頂点 / 面 | 平均内積（前→後） | 第5百分位（前→後） | 最大頂点変位 |
| --- | ---: | ---: | ---: | ---: |
| 全脳用小脳 | 39,696 / 78,976 | 0.7864 → 0.9321 | 0.2839 → 0.7453 | 0 mm |
| 後脳標本用小脳 | 46,401 / 90,978 | 0.7560 → 0.8822 | 0.0867 → 0.1733 | 0 mm |

## Windows実ブラウザ確認

- 左外側面: 大脳の灰白色と小脳の黄褐色が分離し、小脳半球の凹凸と輪郭を保持。Canvas 1、読込残り0、画面内エラー0。
- 下面: 小脳を戻す／外すを実操作し、両半球と虫部方向の凹凸を確認。橋・延髄や模式レイヤーの色と混同しない。
- 水平断の全脳3D: 「分節」で2方向とも小脳が同じ黄褐色になり、大脳皮質・脳幹・内部構造から区別できる。Canvas 3、画面内エラー0。
- 後脳標本: 小脳を外す／戻すを一往復し、第四脳室・小脳脚の表示と状態が同期。Canvas 1、画面内エラー0。

## 残る制限

小脳メッシュは1 mmアトラスラベル由来で、実際の細かな小脳葉・裂を完全には再現しません。法線平滑化は照明の連続性だけを改善し、元ラベルの分解能や境界の正確性を高めるものではありません。小脳葉・小脳核の正確性は専門家レビュー待ちです。
