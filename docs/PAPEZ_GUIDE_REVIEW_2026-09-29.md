# Papez回路ガイドの教材表現（2026-09-29）

6段階の主文を「その段階でどこを探し、次の構造とどう結ぶか」に変更した。断面分節・模式補助・アトラス3Dの由来と収録範囲は折りたたみ欄に残す。視床前核は独立分節されておらず、視床全体が着色される。帯状回・海馬傍回・嗅内野は同一BigBrain標本の断面分節ではない。脳弓の表示も部分収録で、線維一本ごとの追跡ではない。したがって、画面上の連続を標本上で検証された投射経路と同一視しない。

教育内容の照合に用いた資料：

- [UTHealth Neuroanatomy Online: Limbic System, Lab 11](https://nba.uth.tmc.edu/neuroanatomy/L11/Lab11p06_index.html) — 海馬体、脳弓、乳頭体、視床前核、帯状回、帯状束、海馬傍回の概略関係。原Papez回路を単純化した説明である点も確認。
- [UTHealth: Descending fornix pathways](https://nba.uth.tmc.edu/neuroanatomy/L11/Lab11p09_index.html) — 交連後脳弓と乳頭体方向の関係。
- [UTHealth: Hippocampal formation](https://nba.uth.tmc.edu/neuroscience/s4/chapter05.html) — 嗅内野から海馬体へ戻る関係。

出典は教育説明の確認に用いたものであり、このアプリの個々のラベル境界を専門家が確認したことは意味しない。
