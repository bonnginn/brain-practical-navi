# 海馬側へ向かう脳弓脚の延長1,034点

同一BigBrain native100原画像で、既存の脚端（Y660）から海馬側へ続く帯を左右別々に追跡した。左Y600–660、右Y620–660を概略収録し、左474・右560点を0→46で追加。ID46は4,461点、左右2,207・2,254点の2成分となり、どちらも既存の体部・柱側へ連続する。海馬本体・脳室・他のラベルは変更していない。

## 画像判断

広域冠状Y540/580/600/620/640/660を海馬の既存輪郭とともに比較。右側では海馬の上方へ続く帯がより前方の冠状位置に現れるため、左右を同じ前後距離で延長しない。既存輪郭は位置の目印として使用し、真の境界とは扱わない。

手動の概略輪郭から1,180候補を作成。既存の別ラベル69点と、原画像中心がほぼ白色の75点を保留した。白色判定は腔・標本の欠けを再確認するための除外補助であり、組織の明るさだけで脳弓と決めていない。残る1,036点について、冠状4・矢状2・水平2の原画像／投影比較を確認し、新たな孤立2点を表示上保留して1,034点を採用した。セル縁の部分体積は許容し、細い境界の完全一致を採用条件にしていない。

`work/fornix-fimbria-extension-20260920/` に広域図、輪郭、初案、除外理由、最終比較8図（`footprints-tissue/`）、復元用stageを保持。初回投影図の記録出力で変数名の衝突があり、描画済み8図を再生成せず目録を復旧した。最終比較図は修正済み描画器で正常に生成した。
