# 視覚路の収載端と残る分節条件 — 2026-09-16

視交叉・視索の旧ID33は今回の3修正で変更していない。旧範囲の全冠状surveyと代表直交断は再利用し、同じ未解決界面を再探索しない。ID36–38は0点のまま、学習用断面ラベルや通常クイズにも追加しない。現行の模式3Dは維持する。

## 視放線を教材に収録する範囲

| 区間 | 収載したい範囲 | 分節前に必要な確認 |
| --- | --- | --- |
| 外側膝状体側 | 視床全体ではなく、外側膝状体から出る白質側を開始端とする | BigBrainで外側膝状体を周囲の視床・視索と区別し、束へ入る位置を原画像で確認する |
| 側頭葉内の前方湾曲 | 側脳室下角と関係するMeyer loopを別の観察区間として扱う | 脳室の形や別標本の平均距離だけで湾曲を描かず、周囲の鉤状束・下前頭後頭束等から区別できる根拠を得る |
| 後方の矢状層 | 脳室外側〜後頭葉へ向かう区間を追う | 同じ白質層にある前交連系や縦走線維と、視放線を一括して塗らない |
| 鳥距溝側 | 一次視覚皮質に近い白質側までを終端とする | BA17の別脳表モデルを組織格子へ直接転写せず、標本側の鳥距溝・皮質との関係を確認する |

[Microsurgical anatomy of the sagittal stratum](https://pubmed.ncbi.nlm.nih.gov/31363919/) の一次線維解剖研究は、矢状層の深層で視放線と前交連線維が混在し、その外側にも別の白質束があることを報告している。このため、周辺白質の明るい帯を丸ごと視放線として塗る方法は採用しない。これは原画像への適用上の判断であり、この論文がBigBrainの個々の境界を同定したという意味ではない。ブラウザの日英参考文献にも掲載する。

今回、視放線そのものをBigBrain上で追跡した新しいmaskは作成していない。原画像の収載端が確定するまでは、既存の模式polylineをラベル化せず保持する。次の作業は上記4区間を一度に塗ることではなく、外側膝状体側の短い開始区間を同定して、原画像で束を区別できるかを確認することである。識別できない場合は、その区間を画像付きで保留し、別標本の転写で完成扱いしない。

視交叉／視索の既存証拠と残る境界は [2026-09-14の範囲決定](VISUAL_PATHWAY_SCOPE_DECISION_2026-09-14.md) に記載されている。専門家確認・ラベル追加・公開更新は今回行っていない。
