# 脳梁と帯状回側組織の広域境界修正 — 2026-09-30

公開後の確認で、脳梁ID30は上縁の数点だけでなく、左右外側寄りの帯状回・帯状束側まで長い帯として塗られていた。従来の小成分単位の修正では教材上の誤表示が残ったため、矢状断で脳梁本体の白質と上方の帯を分け、冠状断と隣接位置でその連続性を確認した。

BigBrain原画像、既存ラベル、独立した登録済み組織分類を並べて照合した。組織分類の灰白質・第I層は上方の帯を見分ける根拠になったが、白質分類には脳梁と帯状束の両方が入るため、それだけで境界を決めていない。各外側寄りの矢状列で原画像上の境目を追い、正中近傍の脳梁弧を保持して候補を作成した。矢状・冠状の代表図は `work/anatomy-review/callosum-cingulate-post-release-20260930/candidate-*.png` と `candidate-coronal-*.png`。各図のSHAは採用記録に固定した。

開発版では48,395点をID30から未ラベル0へ戻した。ID30は145,429点から97,034点、圧縮ラベルSHA-256は `f2c489829d1b0d9515bcced16e42bb2daff25fa15f2d169e75ee5065ea001721` から `71f012431e3bd605deabc8d19b9cdaf1d35dff076f54e7a9f84a32e3a4eb5866` になった。組織を「消した」のではなく、誤った脳梁名の適用を外した。帯状回や帯状束への新規割当はしていない。正確な昇順indexと採用条件は [`segmentation-patches/review/callosal-cingulate-broad-2026-09-30.indices.bin.gz`](../segmentation-patches/review/callosal-cingulate-broad-2026-09-30.indices.bin.gz) および [`採用記録`](../segmentation-patches/review/callosal-cingulate-broad-adoption-2026-09-30.json) に保存し、変更前volumeの復元と逆適用を照合した。
