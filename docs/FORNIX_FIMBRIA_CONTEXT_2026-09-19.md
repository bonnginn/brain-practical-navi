- 矢状X480/520/900/950。Y540–780、Z450–730で、海馬後方の折り返しとその上縁を確認した。

成果物・原画像のcrop条件・画像SHA・現行ラベルSHAは `work/fornix-fimbria-context-20260919/` の各 `report.json`、生成コード、PNGに保存。冠状の後方3面は `posterior-v1/`、矢状4面は `sagittal-v1/`。

## 所見と次の対象

海馬上縁の薄い組織帯と、脳室内側のより上方にある帯状組織を位置関係として確認した。両者の間には高さと前後位置の変化があり、同じ冠状断上で直線的に塗りつないではならない。左右は同一Yで形態・ラベル投影が異なるため、左右反転や同じ輪郭の複製を使わない。海馬ラベルの消失を海馬そのものの終端と解釈しない。

次は、海馬後方の上縁から脳室内側へ折り返す区間を左右別に追う。追加cropの探索範囲はnative100で左X500–590 / Y580–650 / Z590–660、右X830–960 / Y600–680 / Z580–660を目安とする。これらは境界・採用候補・確定した海馬采maskではない。既存11図から位置を再発見せず、この範囲の連続断と水平断を補う。海馬白板、海馬采、脳弓脚、上方の脳梁側との区別と、現在の後方収録部までの連続性が不足している。

走行と付着の比較方針は既存の [境界判断資料](FIBER_BOUNDARY_METHODS_2026-09-16.md) と [後方追跡](FORNIX_CRURA_CONTEXT_2026-09-19.md)を継続する。別標本の境界転写や、原画像で識別できない帯の一括登録はしない。

## 海馬後方から既存収録部の間を追加確認

`transition-v1/` の左右別18図（冠状10・水平8）、`bridge-v1/` の11図（冠状4・水平3・矢状4）をすべて確認した。nearest-neighbor拡大で原画素を保持。左Y620–650、右Y640–680で、海馬後方上縁から上方の帯状組織へ移る形態を認める。Y660–690の左右の帯を、既に確認済みのY700側へ追う区間を具体化した。内側の付着部、海馬白板／海馬采の名称境界は依然未確定。

Y660/670/680/690で左右独立の内部輪郭案を描き、Y700は以前の輪郭形状を再利用した。`interior-draft-v1/` の原画像／輪郭比較9図（Y660–700、5刻み）を確認。これは全外縁ではなく内部の細い範囲であり、採用済みmaskではない。

`app-candidates-v1.json`：現行アプリ格子へ変換すると中心を含む候補は左241・右256。そのうち中心・角・面／辺中点の27サンプルが内部輪郭に収まる点は左51・右0、左51はすべて現行ID0。逆変換残差最大約0.000003 mmは数値変換の確認にすぎず、解剖学的妥当性を保証しない。

左51の実voxel投影を `footprints-v1/` の冠状9・矢状4・水平3、計16図で確認した。表示した面では帯の内部に投影されるが、全voxelの全断面や全外縁を確認したとの主張ではない。小cropの図では長いヘッダが切れるため、軸・位置は同フォルダreportとファイル名を参照する。

既存ID46との6近傍成分を調べると、新規51点は22/20/6/2/1点の5片となり、既存左977・右817とは接続しない（`component-review-v1.json`）。51点を浮いた小片として追加することは保留した。これは組織の欠如や解剖学的棄却ではなく、細い内部案を0.5 mm格子へ移した場合の表現上の問題。右0点も構造の欠如を示さない。

次は同じ概観を再生成せず、Y660–700の原画像で見える厚みまで輪郭を見直す。左の現在の案には明らかに組織内の余白があり、右も薄い内側と厚い外側を一律に扱わない。内側付着部、左Y675付近の線状の明るい裂隙、右の腹側縁を個別に避け、全体包含を満たすためだけに輪郭を広げない。51点や中心候補497点を連結目的で一括登録しない。
