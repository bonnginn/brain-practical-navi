# 学習ワークスペースの再構成 — 2026-09-26

ユーザー指示：既存配置を縮小するだけでなく、同じ機能を保って情報設計から見直す。なるべく1画面で主要操作を完結させ、必要なら補助文字を小さくする。指定された入口の文章は保持。

## 構成

- 共通の教材ナビを1段にまとめる。出典・利用条件・共同制作・報告は既存の「出典など」に集約。狭いPC幅や英語では2段へ折り返す。
- Homeを4つの教材へ直行するカードに変更。説明・自己確認の問いは各カードの「観察のポイント」に保持し、更新通知は教材選択の下へ移動。
- 自由観察は「構造を探す」「回路をたどる」を切替。検索、索引、複数選択、部位解説は維持。回路を選ぶと回路側を開く。構造側への切替では隠れた回路再生を停止する。
- 回路選択はドロップダウン、学習目標と重複する観察順は折りたたみ。再生操作を早く見つけられる配置に変更。
- 3Dと表示操作を残し、段階の技術的ラベルの重複を減らす。表示範囲・出典・視床前核未分節などの必要な説明は保持。
- ブロックの左欄は選択を優先し、区分の説明を折りたたむ。ブロックには前回の全脳用84%縮小を適用せず、元の倍率へ戻す。
- 説明欄は本文13–14px程度、主要操作14–18px程度を中心に整理。スマートフォンのタッチ領域は維持。

実装は既存イベントと教材データを再利用する。分節・モデル資産・公開データは変更しない。長文を展開したときや構造を多数選択したときのスクロールは許容する。
