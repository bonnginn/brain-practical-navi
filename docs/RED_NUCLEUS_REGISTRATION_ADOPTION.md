# 赤核の位置合わせ修正（開発版、2026-09-06）

ユーザーが原画像との比較改善を認め、扱いを委ねて修正を依頼したことに基づき、左右赤核ID1・2のみを高精度位置補正候補から採用した。AI補助のプロジェクト判断であり、専門家レビューではない。全22ラベルの一括採用、main統合、公開は行っていない。

## 白い帯の扱い

赤核を「外周で囲まれた核全体の領域」として扱い、元手動区画内の明るい帯を強度閾値で穴あけしない。白い組織そのものを赤核の灰白質や特定の線維束と同定した意味ではない。赤核内には通過線維があり、外形ラベルと純粋な灰白質マスクは同じではない。[動眼神経線維の微細解剖研究](https://pubmed.ncbi.nlm.nih.gov/23242853/)。今回の局所の線維名・細胞構築学的境界は未確定。

前の[全22ラベルの確認結論](MANUAL_REGISTERED_REVIEW_CONCLUSIONS.md)と赤核54比較断面、数値精度差の追加確認が位置修正の根拠。新たな濃淡分類、形態学的膨張・平滑化、線維の推測塗りはしない。

- ブロック標本の赤核部品も同じ修正ラベルから再生成。既存の10 mm範囲、1 mm形状採取、表示用meshing条件は維持。断面の0.5 mmラベルそのものを平滑化したわけではない。他のmeshは変更しない。
- 断面と赤核meshのキャッシュ版を更新。古い観察リンク・編集差分は従来どおり版照合の対象。

## 検証範囲

Python／JavaScript双方で全差分の正方向・逆方向再生、他ID不変、改変・重複・別構造への書込み拒否を検査した。全Python88/88（83.134秒）、全Node491/491（167.132秒）、TypeScript型検査、通常本番build、GitHub Pages用baseでのbuild、git diff --checkに成功。buildには既存の大きいchunk警告がある。新しい実ブラウザでの目視合格は未記録であり、過去の撮影を今回の合格へ流用していない。プレビューのHTTP200のみ確認し、127.0.0.1:4345を案内した。公開・main統合・commit/pushは未実施。

過去の全22候補の研究スクリプトは入力098edf…のSHAを維持しているため、新しい開発volumeを渡すと安全側に停止する。再実行する場合は今回保存したpre-red-registration fixtureを研究入力として明示的に使用する。旧レビュー結果を新しいvolumeへ無条件に引き継がない。

ID3–22の位置補正は未採用。赤核内の白い帯の組織同定、赤核亜領域の細分、他の後付け神経・血管の修正はこの採用では解決していない。
