# 断面の1枚送り — 2026-09-08

開発版・未公開。微細構造の見落としを減らすため、BigBrain断面に「−1枚／＋1枚」を追加した。従来の1%移動では約4–5 voxel進み、矢状断50%から中心X195–196を選べなかった。

- 3方向とも実際の0.5 mm格子で1枚移動する。水平断のZ逆向きを含め、既存の格子変換を共用する。
- スライダーは連続操作を保ち、左右矢印キーは1枚ずつ移動。ボタン・キー操作は自動再生を停止する。両端のボタンは無効になる。
- X/Y/Zの格子番号を表示。一般的な「位置」は小数2桁までとし、描画・観察リンク・保存状態の精度は丸めない。
- 別ソースのMRI・MNIへBigBrainの格子寸法を流用せず、1枚送りはBigBrainのみ。ラベル本体・XYZ定義・半球左右を変更しない。
- 日英対応。新規ボタンは44px高を確保し、狭幅でも3列で並ぶ。
