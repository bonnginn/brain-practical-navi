# 3D選択色・可読性監査

更新日: 2026-08-14

## 対象

脳表の外側面、上面、下面、内側面で同時選択できる皮質領域色を対象にしました。色だけを正解手掛かりにせず、構造名、ラテン名、選択状態、表示中カードを併記する設計は維持します。

## 判定方法

- 各観察方向で同時選択できる色の単純sRGB距離を計算し、35未満の組を近似色として見直す。
- 3D背景 `#1a1f21` に対する元色のWCAG相対輝度比を3:1以上にする。これは3D陰影そのものへのWCAG適合を主張する値ではなく、暗背景へ沈む色を検出する内部基準です。
- 自由観察では26領域を選べるため、色だけに依存せず、検索結果、選択カード、構造名、解除ボタンを常時併用する。

## 修正結果

| 観察方向 | 修正前の最小sRGB距離 | 修正後 |
| --- | ---: | ---: |
| 外側面 | 20.5（中心後回／縁上回） | 36.3 |
| 上面 | 38.9 | 38.9 |
| 下面 | 24.8（眼窩前頭皮質／舌状回） | 37.6 |
| 内側面 | 7.5（帯状回／舌状回） | 49.7 |

縁上回、外側後頭皮質、中側頭回、眼窩前頭皮質、帯状回を調整しました。修正後は全26領域が暗背景に対して3:1以上で、方向別の最小色距離は35以上です。自動テストでこの下限と、名称・`aria-pressed` を併用するUIを固定します。

Windows実ブラウザで外側面6領域と内側面5領域をそれぞれ全選択し、色面、構造名カード、選択状態が一致することを確認しました。Canvas読込エラーはなく、無着色皮質と選択領域の境界も視認できました。

## 制限

- sRGB距離は知覚均等色空間ではなく、色覚特性の個人差を保証しません。
- WebGLでは照明、溝の陰影、重なりにより見かけの明度が変わります。
- 専門家レビューでは色だけでなく、境界の位置と構造の見え方を別に確認します。
