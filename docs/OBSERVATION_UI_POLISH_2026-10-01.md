# 追加教材を含む断面UIの整理（ローカル）

ユーザーが観察中だった視床・外側膝状体・脳幹の3構造表示を基準に、増えた説明と補助教材の配置を整理した。

- 選択済み構造は名称と色の短い切替ボタンにした。現在の対象と働きは上段、詳しい位置関係・収録範囲・由来は「詳細解説」で確認する。選択中の対象は見た目と `aria-pressed` の両方で示す。
- 観察ガイド・視床ガイド・実標本動画・共有リンクは見出しの形を揃え、デスクトップでは2列、狭幅では1列にする。断面の補助教材だけを同じnative detailsグループにし、同時に複数開いて長く積み重なるのを防ぐ。他の画面のガイドは独立したまま。
- 視床ガイドは図と選択中の説明を優先するcompact表示にした。核群の一覧は「ほかの核群・中継部に切り替える」で開く。外側膝状体が現在の対象なら初期表示をLGNにする。ガイドを開くと連続断面再生を止める。
- 狭幅の構造切替と補助教材の見出しは44pxの操作高さを確保する。

断面の高さを削って主な役割まで初期画面へ詰める案は、低い画面で3Dが読みにくくなったため不採用。画像とスライダーを優先する既存の高さ計算を維持した。入口の固定文言、分節、四択、集計、公開版は変更していない。

型検査・通常build、機能概要と観察リンクの既存5試験を確認。実ブラウザで構造切替→機能説明→詳細解説、LGN初期表示、補助ガイドの排他的開閉、日英切替を確認。390×844のviewport指定で実際のCSS幅は295pxになったが、日英とも横はみ出しがなく、切替ボタンは約44pxだった。物理タッチ端末・Safariは未確認。native detailsの排他グループ未対応のブラウザでは個別開閉へ劣化するが、内容は失われない。分節検査・全件試験は繰り返していない。

最終確認先は `http://127.0.0.1:58806/`、出力は `work/october2-ux-preview`。画面は `work/october2-compact-observation-ja.png`。ユーザーが使っていた52583のタブと4648のタブは保持し、途中の試行タブと試行プレビューは終了した。新しい最終プレビューは稼働を維持した。
