# 教材としてのガイドツアー案

2026-09-08 JST／検討案。学習者画面への実装・公開はまだ行っていない。分節の修正とは独立した教材設計として保存する。

## 最初に作るもの

**「視床を3Dと三断面で見つける」短いツアーを一つ作り、実際の学習者に試してもらう。** 最初から全回路のツアーを揃える必要はない。観察の順序、画面操作、問いの難しさをこの一本で確かめる。

想定対象は神経解剖実習の初学者。医学生等を当面の想定とするが、正式な学年・授業時間・到達目標は未確定。所要時間は6〜8分程度を設計上の目安とし、実測後に調整する。学習効果はまだ検証していない。

学習後の到達目標は、(1)左右の視床全体を示せる、(2)断面の向きが変わっても同じ構造を追える、(3)全視床ラベルだけでは個別核の境界を示せないと説明できること。

## 一段階の学習体験

画面を開いたら観察場所と一つの問いを示す。学習者が操作・回答してから短い説明を見る。

1. **見る場所**：対象と断面を表示。例「左右の視床を見比べよう」。
2. **試すこと**：操作は一つ。例「着色を外して、右の視床を選んでください」。
3. **考える問い**：形・位置・前後のつながりを一つだけ問う。
4. **ヒントと説明**：ヒントは「方向の手掛かり」→「対象の着色」の二段階。いつでも説明を開ける。
5. **次への接続**：例「今見た場所を、水平断でも探してみよう」。

進む操作は学習者に任せる。初期版で自動再生・制限時間・音声は必須にしない。自由に回転や断面移動をしてもよく、「この段階の見え方に戻す」で復帰する。

## 第1ツアーの具体的な台本

核の細分化前でも準備できる構成。下表の文言は教材原稿の下書きであり、採用前に現行画像で見え方を確認する。

| 段階 | 表示・操作 | 学習者への問い／案内 | 説明・判定 |
| --- | --- | --- | --- |
| 1 向きをつかむ | 冠状断、左右・上下の方向表示。最初は着色なし | 「画面のLとRを確認しましょう。これは標本のどちら側を表していますか？」 | 画面上の左右と解剖学的な左右の扱いを説明。方向表示を基準にする |
| 2 左右の視床を見つける | 現行ID15/16が見える冠状断へ。最初に左だけ着色 | 「反対側の視床はどこでしょう？」 | 選択後に両側を着色。境界付近のクリックは即座に誤答とせず、位置を確認できるヒントを提示 |
| 3 周囲との関係を見る | 同じ断面で左右視床と第三脳室を表示 | 「左右の視床の間にある、正中の腔を探しましょう」 | 第三脳室との位置関係を確認。表示範囲に腔がない場合はこの段階を開始せず、利用可能な断面を再選定 |
| 4 3Dへつなぐ | 視床の断面対応3Dと切断面を並べる | 「この断面は、視床のどの高さを通っていますか？」 | 高さを予想してから切断面を示す。回転して確認し、元の視点へ戻れる |
| 5 別の断面で追う | 同じ参照点へ水平断、次いで片側の矢状断。1枚送り | 「断面の向きが変わっても、同じ側の視床を追えますか？」 | 新しい中央位置へ飛ばさず同じ標本座標を維持。矢状断では前が左、後が右という現行方向表示と対応 |
| 6 自分で探す | 着色と名称を隠す。事前確認した別の近接断面 | 「視床を示し、手掛かりにした構造を一つ挙げてください」 | 同定の試行と自己説明。自動採点は既存ラベルの範囲内に限定し、説明は自己確認用。自由記述の自動正誤判定は導入しない |
| 7 次の学びを選ぶ | 全視床の表示に戻り、核の学習への案内 | 「この色だけで、視床の個々の核の境界も分かるでしょうか？」 | 全体のラベルと核の細分化を区別する。核の詳細位置が未登録なら「準備中」とし、存在しない詳細表示へのボタンを出さない |

第3段階の関係説明は既存の[内容正確性レビュー](../../docs/CONTENT_ACCURACY_REVIEW.md)を根拠に再利用する。第4・5段階はUI実装と実画像確認が必要。表中の問いがあるだけで教材の検証済みとはしない。

参照位置には[神経回路準備の参照点](../neural-circuits/context-inventory.json)を利用できる。ただしこの記録は入力SHA付きのスナップショット。ツアー採用時は現行データで再計算し、第三脳室を含む必要構造の断面上の存在を別途確かめる。左右視床の参照点は個別核の位置として利用しない。

## 拡張するツアー候補

| 順序案 | ツアー | 学ぶこと | 追加前の条件 |
| --- | --- | --- | --- |
| 1 | 視床を見つける | 三断面・3Dの対応と周囲の位置関係 | 上記7段階を試作して実機・教材レビュー |
| 2 | 基底核の構造を見分ける | 尾状核、被殻、GPe/GPi、視床下核、黒質の同定 | 既存ステッパーの各段階に問いと再同定を追加。興奮／抑制の説明は接続資料の確認後 |
| 3 | 脳室を連続断面で追う | 腔が断面上でどう変化するか | 第三・第四脳室、中脳水道の部分収録を段階ごとに明示。未収録区間を飛ばして「全経路を追えた」としない |
| 4 | 記憶回路の構成要素を訪ねる | 海馬、脳弓、乳頭体、前核群などの関係 | 既存Papez表示の由来を再点検。前核群や線維路が未確認の段階は名称・概念図の説明に留める |
| 5 | 感覚情報の中継を学ぶ | 視覚／聴覚／体性感覚と関連する核 | LGN/MGN、VPL/VPMの位置・接続を確認後に、系統ごとに短いツアーを作る |

この順序は開発の案。既存教材と授業で使いやすい範囲から始める。複数の未確認構造を一度に追加する長いツアーは初期版の対象にしない。

- [経路ステッパー](../../src/pathwayStepper.mjs)：基底核5段階、Papez6段階の位置関係表示。個別核・線維走行を新たに確定するものではない。
- [断面の幾何](../../app/segmentationGeometry.ts)：三断面の方向と1枚送り。
- [新しい座標接続の準備](../neural-circuits/coordinates.mjs)：同じ科学座標を断面位置・3D表示座標へ変換。

新しいツアーは学習目標・問い・説明・確認操作を持つ進行管理を追加し、表示は既存機能に依頼する。核の名前、色、ラベルID、由来をツアー原稿へ重複コピーしない。既存のブロックガイドを解剖学的な摘出順や学習達成の順序として読み替えない。

一段階の原稿には次の欄を持たせる。実行用のスキーマは実装着手時に確定する。

| 欄 | 内容 |
| --- | --- |
| ID・原稿版 | 保存した進捗と改訂後の原稿を取り違えない安定ID |
| 学習目標 | この段階で何を説明・同定できればよいか |
| 表示要求 | 対象ID、必要な表示（断面／3D／概念図）、参照点、必要な由来区分 |
| 問い・ヒント・説明 | 短い本文と説明の出典。表示名称は共通辞書から取得 |
| 必要条件 | 対象資産、入力SHA、対象画素の存在、位置・境界・説明それぞれの確認状態 |
| 進め方 | 観察、クリック同定、予想、自己説明のいずれか。必須解答か任意か |
| 表示できない場合 | 代わりの観察、本文だけにする可否、学習未完了の扱い |

## 操作と進捗の扱い

- 初期表示に「何を学ぶか」「段階数」「時間の目安」を短く表示する。すぐ始められる入口を既存ホームか関連観察画面に置く。入口の増設位置は一本目の試作時に決める。
- 各段階は「前へ」「次へ」「ヒント」「見え方を戻す」「終了」を基本とする。自由観察を妨げず、見え方を変えただけで自動的に次へ進まない。
- 開始時に表示状態を保存し、終了時に復元する。保存対象はworkspace、断面・位置、選択・着色、3D視点、ズーム・パン、表示配分。現在の観察リンクには回転・拡大率が含まれないため、リンクだけを復元機構に使わない。
- ツアーと既存ステッパーの同時再生を避ける。画面切替、終了、タブ非表示時の動作を定義し、不要なタイマーを止める。
- 初期版では進捗を端末内に保存する案。ツアーID・原稿版・段階ID・利用したデータ版を保存し、原稿やデータが変わった際は再確認が必要な段階を示す。学習者アカウントや成績送信は追加しない。
- 「閲覧した」「ヒント付きで確認した」「ヒントなしで再同定した」を分ける。全ての「次へ」を押しただけで「習得済み」としない。スキップした必須目標は確認未実施として残す。
- スマートフォンは3Dと断面を切替表示できるようにし、問いと操作が画面外へ隠れない配置にする。色だけで区別せず文字・輪郭を併用。キーボード操作と動きの軽減に対応する。
- 読込み失敗時はその段階を保持し、再試行できるようにする。WebGLが使えず断面だけで進めた場合、3D対応の目標は確認未実施として扱う。

## 最初の試行で確かめること

少人数の初学者に一本目を試してもらい、まず下記を観察する。人数・評価基準は試行前に定める。これは教育効果を実証する研究計画ではなく、教材改善のための試行案。

1. 指示を聞き直さずに次に行う操作が分かるか。
2. 別の断面でも、左右を取り違えずに視床を再同定できるか。
3. 着色した輪郭を暗記するだけでなく、手掛かりを一つ説明できるか。
4. 全視床と下位核の違い、模式表示と標本由来の表示の違いが伝わるか。
5. 途中離脱から復帰できるか。ヒント・画面切替・読込み待ちでどこに迷うか。

自動クリック採点では境界の誤差と学習上の誤りを混同しない。成績や完走率だけで良し悪しを決めず、迷った画面と指示文を改善する。評価の収集や他者への連絡はまだ行っていない。

## 今回の結論と次の一手

ガイドツアーは今後の教材機能として具体化する価値がある、という開発上の提案。初期版は**視床全体の位置を自分で探せる一本**に絞る。核の細かな位置の追加と並行して原稿・操作設計を進められる。

今回完了したのは既存機能の調査と本案の保存。実装、利用者試行、解剖学的な画面検証は未実施。次の実装単位は「7段階の原稿→既存表示への接続→状態の復元→一段階ずつの画面確認」とする。
