# 神経解剖学コースへの方針変更

2026-09-08。ユーザーの補足により、短いガイドツアーを並べる案から、**神経解剖学を基礎から一通り学ぶ体系的コース**へ変更した。

現在の全体設計は [神経解剖学コース：18章・54課](../neuroanatomy-course/README.md)。本文、観察、演習、解答解説、章末確認、復習と進捗を一つの学習体験として構成する。設計段階であり、全課が実装済みではない。

以前の原稿は廃棄せず、コース内の観察演習として再利用する。

- [視床と三断面の原稿](THALAMUS_LESSON_DRAFT.md)：第02章の断面・立体の対応と第08章の視床観察へ組み込む素材。
- [ブロードマン観察の原稿](BRODMANN_PILOT.md)：第04章の脳表・細胞構築と第17章の機能との区別へ組み込む素材。

このディレクトリ名は旧案の保存場所として残す。新しい教材の入口や製品名を「ガイドツアー」とする方針ではない。
